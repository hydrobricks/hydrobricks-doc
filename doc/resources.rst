.. _resources:

Resources
=========

This page lists useful resources provided by the community.
Please add your own if you think it may be of interest to others.


Using hydrobricks
-----------------

* `Hydrobricks-getting-started <https://github.com/MilesThomi/Hydrobricks-getting-started>`_:
  a structured, reproducible workflow for setting up, calibrating, and analysing
  discharge simulations in alpine catchments using hydrobricks.


Postprocessing
--------------

* `glacial-discharge-downscaling <https://github.com/ALArgentin/glacial-discharge-downscaling>`_:
  code for downscaling hydrobricks daily outputs to sub-daily timescales (flow
  duration curves) in alpine glacierized catchments.
